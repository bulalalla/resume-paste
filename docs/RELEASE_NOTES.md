## 简历随手贴 v0.4.0 · 简易版

跨平台桌面简历投递助手，提供 Windows、Linux 与 macOS（Intel / Apple 芯片）版本。

- 半透明置顶面板，基本信息分别复制，工作内容整段复制。
- 左键复制文本、右键复制绑定的文件路径 / URL，支持自定义鼠标和键盘操作。
- JSON 导入、手动编辑、分组模板、家庭联系人、材料绑定及备份。
- Ctrl+Space 折叠 / 展开，可自定义；设置在本机保存。

### 下载

Windows 选 setup 或 portable；Linux 选 AppImage 或 tar.gz；macOS Apple 芯片选 arm64，Intel 选 x64。

`resume-paste-demo.zip` 包含虚构简历 PDF / JSON / Markdown、示例证明材料和教程。导入其中的 `test-resume.json` 即可体验。

这是未签名、未公证的简易发布版本。Linux 的透明和快捷键效果受桌面环境影响。构建会运行自动测试，但不能替代各系统的人工使用验证。
